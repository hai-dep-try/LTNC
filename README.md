# LTNC - Lập trình nâng cao

Repository này lưu trữ toàn bộ tài liệu học tập, bài giảng và lời giải bài tập cho môn học **Lập trình nâng cao (Advanced Programming)**.

## 📚 Tài liệu bài giảng (Lectures)

Các file PDF được đánh số từ **1** đến **14** là nội dung bài giảng chi tiết theo từng tuần/chủ đề của môn học:

- **1**: Hệ sinh thái Java & Tư duy hướng đối tượng.
- **2**: Thêm về Java.
- **3**: Thừa kế và Đa hình.
- **4**: Lớp trừu tượng, Giao diện, Lập trình tổng quát.
- **5**: Cấu trúc dữ liệu trong Java.
- **6**: Xử lý ngoại lệ - Luồng vào/ra.
- **7 & 8**: Mẫu thiết kế (Design Patterns).
- **9**: Đa luồng (Multi-threading).
- **10**: Tái cấu trúc mã nguồn (Refactoring).
- **11**: Kiểm thử (Testing).
- **12**: Tích hợp và Triển khai (CI/CD).
- **13**: Lập trình Mạng.
- **14**: JavaFX, MVC & Serialization.

## 💻 Bài tập hàng tuần (Weekly Assignments)

- **Đề bài**: Các bạn vui lòng xem và cập nhật đề bài tập hàng tuần trên **Portal** của môn học.
- **Lời giải**: Lời giải chi tiết cho các bài tập hàng tuần được tổ chức trong các thư mục có định dạng `NinhDucHai_25021747_WeekX`.

## 📁 Cấu trúc thư mục chính

| Thư mục / File | Nội dung |
| :--- | :--- |
| `NinhDucHai_..._WeekX/` | Lời giải bài tập thực hành tuần X. |
| `[Số]-[Tên bài giảng].pdf` | Tài liệu bài giảng lý thuyết. |
| `uet-oasis-oop/` | Các dự án hoặc bài tập liên quan đến hệ thống OASIS. |
| `Adjuge-..., Bidscape-...` | Các bài tập lớn hoặc project liên quan. |
